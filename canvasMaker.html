コマンド

基本的なもの

  • start = [xStart, yStart];  冒頭に必ず記述します。描画領域の左下端点の座標を start = [-1, -2]; のように指定します
  • end = [xEnd, yEnd];  冒頭に必ず記述します。描画領域の右上端点の座標を end = [3, 4]; のように指定します
  • 点の名前 = [x, y];  点の座標を pointA = [1, -2]; のように定義します
  • baseLineWidth = 数値; それ以降に用いるすべての線の太さを指定します
    • それ以降に用いるすべての線の太さ(px)が指定した値となります。 各種コマンドの width 属性に指定がある場合は, そちらが優先されます。
  • baseColor = '色の種類'; それ以降に用いるすべての線, 文字, 塗りつぶしの色を指定します
    • それ以降に用いるすべての線, 文字, 塗りつぶしの色を, 例えば 'red' のように指定します。既定値は 'black' です。 各種コマンドの color 属性に指定がある場合は, そちらが優先されます。色の種類については次をご覧ください。
    WEB色見本 原色大辞典 - HTMLカラーコード
  • baseFont = 'フォントのサイズ・スタイル' ;  それ以降に用いるすべてのフォントのサイズ・スタイルを指定します
    • それ以降に用いるすべてのフォントのサイズ・スタイルを ' 20px serif ' や ' 15px arial ' のように指定します。既定値は ' 20px serif ' です。各種コマンドの font 属性に指定がある場合は, そちらが優先されます。 使えるフォントについては以下をご覧ください。ただし, すべてを使えるわけではないようです。
    総称ファミリ名分類のフォント名一覧
  • putString(); 文字列を描画します
    • putString({
    at : [x, y],
    必須。文字列を描画する座標
    string : '文字列',
    必須。描画したい文字列
    color : '色の種類'
    オプション。文字列が指定した色になります。既定値は baseColor (変更していない場合は 'black')。circle・box・arrow オプションをつけた場合の線・塗りつぶし・矢印の色にもなります
    font : 'フォントの種類・サイズ',
    オプション。文字列が指定したフォント・サイズになります。既定値は baseFont (変更していない場合は' 20px serif ')です
    move : [数値, 数値],
    オプション。文字列の位置を調節するベクトル量です。単位は, そのコマンドにおいて描画される「x」の幅です
    circle : true, または false,
    オプション。true の場合, 文字列を円で囲みます。false の場合, 文字列を白抜きにして円で囲みます
    box : true, または false,
    オプション。true の場合, 文字列を四角で囲みます。false の場合, 文字列を白抜きにして四角で囲みます
    width : 数値,
    circle・box・arrow オプションが true の場合の線の太さ(px)が指定した数値となります
    arrow : true,（vector : true）
    文字列の上部にベクトルであることを表す矢印をつけます
    });
  • singlePointMark(); 一点に黒丸(白丸)を打ちます。
    • singlePointMark({
    at : [x, y],
    必須。黒丸を打つ点の座標
    size : 数値,
    オプション。与えた値の 2 倍が丸の半径(px)となります。既定値は 1
    color : '色の種類',
    オプション。丸に用いる色。既定値は baseColor (変更していない場合'black')
    open: true,
    オプション。true の場合, 白抜きの円となります。既定値は false
    width : 数値,
    オプション。open: true の場合に,指定した値の 2 倍が円弧の太さ(px)となります
    });
  • pointMark(); 複数の点に同時に黒丸(白丸)を打ちます。頂点名の描画も同時にできます
    • pointMark({
    points : [
    [ [Xa, Ya], '文字列a' , [moveXa, moveYa] ],
    [ [Xb, Yb], '文字列b' , [moveXb, moveYb] ],
    …],
    [Xa, Ya] は必須。黒丸を打つ点aの座標です。'文字列' はオプション。[moveXa, moveYa] は文字列を描画する場合のオプション。左右の位置の調整です。長さの単位はそのコマンドにおいて描画される「x」の幅です
    size : 数値,
    オプション。与えた値の 2 倍が丸の半径(px)となります。既定値は 1
    color : '色の種類',
    オプション。丸に用いる色。既定値は baseColor (変更していない場合'black')
    font : 'フォントのサイズ・種類',
    オプション。文字列が指定したフォント・サイズになります。既定値は baseFont (変更していない場合は' 20px serif ')です
    open: true,
    オプション。true の場合, 白抜きの円となります。既定値は false
    width : 数値,
    オプション。open: true の場合に,指定した値の 2 倍が円弧の太さ(px)となります
    });

幾何的なもの

  • drawAxis(); 座標軸を描画します。
    • drawAxis({
    type : 'x', または 'y',
    オプション。それぞれ横軸のみ, 縦軸のみを描画します
    xLabel : '横軸の名前',
    オプション。横軸の名前を定めます。既定値は 'x'。'　'(空文字)にすることもできます
    yLabel : '縦軸の名前',
    オプション。縦軸の名前を定めます。既定値は 'y'。'　'(空文字)にすることもできます
    noOrigin : true ,
    オプション。true のとき, 原点Oを描画しません。既定値は false
    });
  • drawLine(); 折れ線(線分)を描画します。破線も描けます。多角形を描画する際にも使えます
    • drawLine({
    between : [
    [x1, y1], [x2, y2], [x3, y3], …
    ],
    必須。結びたい順に座標を入れる
    width : 数値,
    オプション。線の太さ(px)が指定した値となります。既定値は baseLineWidth (変更していない場合は 1)
    color : '色の種類',
    オプション。線の色が指定した色になります。既定値は baseColor (変更していない場合は 'black')
    lineDash : 数値,
    オプション。破線の実線部, 空白部の長さ(px)が指定した値となります
    polygon : true または '色の種類',
    オプション。 true にすると, 始点・終点を結んで多角形を作ります。色の種類を指定した場合, さらにその内部を指定した色で塗りつぶします
    });
  • drawArrow(); 矢印を描画します。破線の矢印も描けます。
    • drawArrow({
    from : [x1, y1],
    必須。始点の座標
    to : [x2, y2],
    必須。終点の座標
    size : 数値,
    オプション。先端の正三角形の一辺の長さ(px)が指定した値となります。既定値は10
    width : 数値,
    オプション。線の太さ(px)が指定した値となります。既定値は baseLineWidth
    color : '色の種類',
    オプション。線の色が指定した色になります。既定値は baseColor(変更していない場合は 'black')
    lineDash : 数値,
    オプション。破線の実線部, 空白部の長さ(px)が指定した値となります
    });
  • drawEnko();  円弧を描画します。
    • drawEnko({
    center : [x, y],
    必須。中心の座標
    radius : 数値,
    必須。半径
    startAngle : 数値,
    オプション。円弧を開始する角度\((^\circ)\)です。３時の方向を 0 とし, 反時計回りを正の向きとします。既定値は 0
    endAngle : 数値,
    オプション。円弧を終了する角度\((^\circ)\)です。３時の方向を 0 とし, 反時計回りを正の向きとします。既定値は 360
    clock : true,
    オプション。true のとき, 円弧の開始位置から終了位置までを時計回りに結びます。既定値は false
    ougi : true,
    オプション。true のとき, 円弧の開始・終了位置を中心と結んで扇型とします。既定値は false
    width : 数値,
    オプション。線の太さ(px)が指定した値となります。既定値は baseLineWidth(変更していない場合は 1)
    color : '色の種類',
    オプション。線の色が指定した色になります。既定値は baseColor(変更していない場合は 'black')
    lineDash : 数値,
    オプション。破線の実線部, 空白部の長さ(px)が指定した値となります
    paint : '色の種類',
    オプション。円や扇型の内部を指定した色で塗りつぶします。開始・終了位置の異なる円弧の場合, 両端を線分で結んでから塗りつぶします
    });
    描画領域の縦・横の単位あたりの長さが異なる場合には drawEnko(); は半径が横方向に radius である円を描画します。
  • angleMark(); 指定した3点 A, B, C に対し \(\angle\mathrm{ABC}\) に角記号(円弧)を描画します。矢印もつけられます
    • angleMark({
    points : [
    [Xa, Ya], [Xb, Yb], [Xc, Yc]
    ],
    必須。線分 ba から線分 bc にいたる正の回転角に記号をつけます
    radius : 数値,
    オプション。与えた数値の10倍が円弧の半径(px)となります。既定値は 1
    clock : true,
    オプション。true の場合, 負の回転角に記号を付けます。既定値は false
    number: 数値,
    オプション。円弧の個数です。既定値は 1
    paint : true,
    オプション。true の場合, 角の内部を塗りつぶします。円弧の個数は強制的に 1 となります
    width : 数値,
    オプション。線の太さ(px)が指定した値となります。既定値は baseLineWidth(変更していない場合は 1)
    color : '色の種類',
    オプション。線や文字列・塗りつぶし・矢印が指定した色になります。線や文字列・矢印の場合, 既定値は baseColor(変更していない場合は 'black')。塗りつぶしの場合, 既定値は 'lightgray'
    string : '文字列',
    オプション。角の内部に描画する文字列
    font : 'フォントの大きさ・種類',
    オプション。文字列が指定したフォントの種類・サイズになります。既定値は baseFont (変更していない場合は' 20px serif ')です
    move : [数値, 数値],
    オプション。文字列の位置を調節するベクトル量です。単位は, そのコマンドにおいて描画される「x」の幅です
    arrow : true,
    オプション。矢印をつけます
    size : 数値,
    オプション。矢印の先端の正三角形の一辺の長さ(px)が指定した値になります。既定値は 10
    bar : true, または false,
    オプション。等角記号 | をつけます。 true と false では入力位置が反対(中心に関し対称)となります。既定値は 「なし (undefined)」
    barNumber : 自然数の値,
    オプション。等角記号 | の本数が指定した値となります。既定値は 1
    barSize : 数値,
    オプション。等角記号 | の長さ (px)を指定します。既定値は 8
    });
  • spiralMark(); 指定した3点 A, B, C に対し \(\angle\mathrm{ABC}\) に周回する角記号(うずまき状)を描画します。矢印もつけられます

    width : 数値,
    オプション。線の太さ(px)が指定した値となります。既定値は baseLineWidth(変更していない場合は 1)
    color : '色の種類',
    オプション。線や文字列・塗りつぶし・矢印が指定した色になります。線や文字列・矢印の場合, 既定値は baseColor(変更していない場合は 'black')。塗りつぶしの場合, 既定値は 'lightgray'
    string : '文字列',
    オプション。角の内部に描画する文字列
    font : 'フォントの大きさ・種類',
    オプション。文字列が指定したフォントの種類・サイズになります。既定値は baseFont (変更していない場合は' 20px serif ')です
    move : [数値, 数値],
    オプション。文字列の位置を調節するベクトル量です。単位は, そのコマンドにおいて描画される「x」の幅です
    arrow : true,
    オプション。矢印をつけます
    size : 数値,
    矢印の先端の正三角形の一辺の長さ(px)が指定した値になります。既定値は 10
    });

canvasMaker.js について

  • canvasMaker.js は主に科学・数学分野で用いる図を描画するための JavaScript マクロです。このサイトでは, canvasMaker.js を用いて実際に描画を行います。作成した図は, 右クリックにより画像ファイルとして保存することができます。
  • コードの入力は, 原則として各種コマンドを「; (セミコロン)」で区切って連ねる ことで行います。見やすさのために適宜, 改行を行ってください。改行は canvasMaker.js の実行に影響しません。また非推奨ですが, 改行を行うことでコマンド間の「; (セミコロン)」を省略することもできます。
  • canvasMaker.js は, テキストエリアにおいて「;（半角セミコロン）」または「Esc」が押されると, コードの解読・実行を試みます。コードが正しければ, ただちにプレビュー欄の描画に変化が起こります。(もちろん, それが実際の描画を伴うコマンドであればです。)
  • デバッグは，ブラウザのコンソールに表示されるエラーメッセージを見ながら行います。
    • chrome なら「その他のツール」→「デベロッパーツール」→「コンソール」
    • firefox なら「その他のツール」→「ブラウザーコンソール」
    • safari なら「設定」→「詳細」の「Web デベロッパ用の機能を表示」にチェック→メニューバー「開発」の「JavaScript コンソールを表示」
    • edge なら
  • コマンドの( )内に入力する引数は JavaScript のオブジェクトです。つまり, { }の中に「属性 : 値 (数値, 配列, 文字列など)」からなる項目を「, (カンマ)」で区切って連ねたものです。最低限, 必須の項目がそろっていればよく, 入力する順番は自由です。
  • コードの入力は原則として,
    • start = [xStart, yStart];
    • end = [xEnd, yEnd];
    の形から始まります。つまり, 描画領域のそれぞれ左下・右上の端点である start・end を, 直交座標におけるどの座標に見立てるのかを宣言するというわけです。
  • その他の各種コマンドについては, 上記の説明やサンプルをご覧ください。
  • HTML の知識をお持ちの方は canvasMaker.js を引用することにより, 各自のウェブサイト上で直接描画を行うこともできます。

    その場合, <head > </head> タグ内で

    <script src = "http://mathemedia.information.jp/canvasMaker.js"></script>

    として canvasMaker.js を引用した上で, <body > </body> タグ内の描画をしたい位置に

    • <canvas id="■■■■" width = ●(ピクセル数) height = ▲(ピクセル数)> </canvas>
    • <script>
    • var myCanvas = document.getElementById("■■■■");
    • var canvasWidth = myCanvas.width;
    • var canvasHeight = myCanvas.height;
    • var ctx = myCanvas.getContext('2d');
    • var baseFont = "20px serif";
    • var baseColor = 'black';
    • var baseLineWidth = 1;
    • ctx.font = baseFont;
    • var margin = canvasWidth / 30;
    • □□
    • </script>

    と記述して, □□ に上のテキストエリアのコードをコピー・ペーストして下さい。 描画領域の横の長さ●, 縦の長さ▲に異なる値を指定して縦長, 横長の図を描画することもできますが, 円や角度に関するコマンドなど描画が乱れる場合があります。

  • テキストエリアの下にある「保存する」ボタンを押すことにより, 作成途中のコードを保存することが出来ます。保存されたコードは, ページ右の「保存済み」エリアに表示されます。保存されたコードを呼び出す際には, その時点でテキストエリアにあったコードは消失しますのご注意ください。
  • コードの保存には indexedDataBase を用いています。indexedDataBase はブラウザごとに設けられたローカルな保存領域を利用します。ブラウザにより「Web サイトデータ」「履歴」「キャッシュ」など, 呼び方は異なるようですが, 該当するものを消去するとコードが削除されますのでご注意ください。 また, ブラウザの更新・再インストールなどでも削除されることがあるかもしれません。
  • このサイト上にコードをサーバーへ送信するようなタグ・スクリプトは含まれていません。また, 筆者の知る限り, 他のドメインではこのサイトで作成された indexedDataBase を読み出すことができません。それでも万全を期すという方は, 機密性のあるコードを保存しないでください。
